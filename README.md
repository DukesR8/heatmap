# Dukes R8 — Heatmap Tile Packages

Pre-rendered enforcement heatmap tile packages for the Dukes R8 app.

## Downloads

Go to [Releases](https://github.com/DukesR8/heatmap/releases) to download individual state/province packages.

Each `.db` file is a SQLite database containing pre-baked heatmap tiles (z10-z14) ready for use in the app.

## Coverage

- 🇨🇦 **Canada**: 13 provinces/territories
- 🇺🇸 **United States**: 50 states + DC
- **Total**: 683,125 tiles across 63 packages

## How to Use

1. Open the app → Settings → Tile Packages
2. Browse available regions
3. Download your state/province
4. Heatmap data loads automatically
